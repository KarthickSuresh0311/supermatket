# Marutham Market

A responsive, interactive supermarket demo for Tamil Nadu. It is built with vanilla HTML, CSS, and JavaScript.

## Local Development

For basic usage, simply open `index.html` in a browser to run it locally.

### Speed Insights Setup (Optional)

This project includes Vercel Speed Insights for performance monitoring. To rebuild the Speed Insights bundle:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build the Speed Insights bundle:
   ```bash
   npm run build:speed-insights
   ```

The Speed Insights will automatically track Web Vitals and performance metrics when deployed to Vercel with Speed Insights enabled in the dashboard.

## Features

Product search, category filtering, quick product views, a persistent shopping basket, location selection, login and checkout demo flows, responsive layouts, and newsletter feedback.
